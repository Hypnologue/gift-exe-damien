# GIFT.EXE — Damien Edition V7

Ouvre `index.html` dans Chrome, Edge ou Firefox. Conserve `visuel.png` et `ours-legendaire.png` dans le même dossier.

## Nouveautés
- Téléchargement automatique en environ 26 secondes, journal des références et bouton accélérer ×3.
- Arrêt à 78 % avec boutons de réparation / révélation.
- Carte collector illustrée de l’Ours légendaire intégrée au booster et à l’impression.
- Barre de succès visible uniquement à la révélation.
- Sauvegarde manuelle, classes évolutives et 8 succès + 1 secret.

## Publication GitHub Pages
Dépose les trois fichiers à la racine d'un dépôt GitHub public, puis active Pages dans Settings > Pages > Deploy from a branch (main, /root). Une fois le site publié, inscris son URL HTTPS sur la carte NFC.

Note : le stockage de la sauvegarde dépend du navigateur et de l'adresse utilisée. Les sauvegardes d'un fichier local ne suivent pas nécessairement celles du site publié.
